# 小词窗 1.1 · 日语随手记

一个放在 Windows 桌面上的日语卡片工具。内置 N5—N1 共 10,641 个日语词条及中文释义，解压后即可使用，不需要账号。

## 开始使用

1. 将压缩包完整解压到你有写入权限的文件夹，例如 D 盘的「小词窗」。不要直接在压缩包预览窗口内运行。
2. 双击 `KotobaWindow.exe`。
3. 在「背单词」左上角展开等级，勾选一个或多个等级后点击「应用所选等级」。初学建议从 N5 开始。
4. 看日语单词，先回忆中文意思，点击「显示答案」或按空格。
5. 按自己的实际记忆情况评分，程序会自动保存进度并切换下一词。

运行环境为 64 位 Windows 10／11 和 .NET Framework 4.8。应用无需安装；如果系统缺少该运行时，需先通过 Windows 更新或微软官方安装程序补齐。词库、检索、复习和内置神经语音均可离线使用。请完整解压，`KotobaWindow.exe` 旁的 `voice` 文件夹是发音所需文件，不能遗漏。

## 卡片怎样用

| 操作 | 用途 |
| --- | --- |
| 多选 N5—N1 | 勾选一个或多个学习等级，再应用；至少保留一个等级 |
| 显示答案 | 显示假名、中文释义与词条备注 |
| 忘记 | 没想起来或答错，约 1 分钟后重新学习 |
| 困难 | 想对了，但很吃力；初次约 6 小时后复习 |
| 记得 | 能正常回忆；初次约 1 天后复习 |
| 轻松 | 能轻松回忆；初次约 4 天后复习 |
| ☆／★ | 收藏或取消收藏这个词 |
| 听发音 | 重播当前词；默认使用内置离线神经语音 |
| 撤销上一次评分 | 撤回最近一次仍可撤销的评分，同时还原该次统计 |

按钮下方显示本次评分后预计的复习间隔。后续间隔会按已有记录调整。这是简单间隔复习算法，不是 FSRS，也不承诺某个固定记忆率。答错时选「忘记」，不要用「困难」代替。

「今日 × 次」统计今天的评分次数，包括同一词反复复习；「待复习」统计所选等级中已经到期的词条。程序优先安排所选等级中到期的旧词，然后学习新词。每天默认最多引入 20 个新词，所有等级共用这 20 个的额度，按电脑本地日期重置。

看到「这一轮完成了」时，说明所选等级暂时没有可安排的卡片，不代表整个词库已掌握。可以等待下一次到期、切换等级，或到「词库」自由查看。请保持电脑日期和时间正确。

## 新词顺序

默认按词库顺序安排新词。在「设置 → 词库与顺序」勾选「新词乱序」，可将所选等级的新词混合打乱。乱序在继续评分和重新打开程序后保持稳定，不会每翻一张卡就重新抽一遍；点击「重新洗牌」才会生成另一套顺序。

乱序只影响新词，到期复习始终优先。切换等级、顺序或重新洗牌不会删除学习记录与收藏。

## 浮窗与快捷键

- 拖动顶部「小词窗」标题移动窗口；拖动窗口边缘调整大小。
- 「置顶／钉住」切换是否显示在其他窗口上方。
- 「小窗／展开」切换紧凑尺寸；双击顶部标题也能切换。
- 在「设置 → 外观与悬浮」选择「亮色」或「暗色」。勾选「透明背景（文字保持清晰）」后，可用 20%—100% 滑块调整背景浓度；卡片与外框采用不同透明强度，文字本身保持不透明。
- 透明模式配合置顶，可叠放在浏览器、编辑器等其他应用上。窗口仍可正常点击、拖动，不是鼠标穿透模式。
- 点击「—」隐藏到系统托盘。双击托盘图标可恢复，右键托盘图标也可显示或退出。
- 点击「×」会保存并退出，不是隐藏到托盘。
- 同时只运行一个实例。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + J | 全局显示／隐藏窗口；窗口隐藏时也可使用 |
| Space | 在背单词页面显示答案 |
| 1／2／3／4 | 翻面后分别选择忘记／困难／记得／轻松；支持数字小键盘 |
| R | 朗读当前词 |
| F | 收藏／取消收藏当前词 |
| Ctrl + Z | 撤销最近一次仍可撤销的评分 |

除 Ctrl + Alt + J 外，快捷键需要小词窗获得焦点。在搜索框或下拉选择框中操作时，学习快捷键不会截获输入。如果全局快捷键被其他程序占用，程序会提示，此时可通过托盘恢复窗口。

## 检索与收藏

进入「词库」，可按日语书写、假名或中文释义搜索，也可多选等级及勾选「只看收藏」。列表最多显示前 200 条，同时显示实际匹配数量；匹配较多时输入更具体的关键词。

双击词条或点击「查看卡片」可打开完整卡片。此时显示「自由查看 · 不计复习」，不会消耗每日新词额度，也不能评分。点击「回到复习」返回正常学习队列。收藏不改变该词的复习时间。

## 设置

- **每天新词上限：**可选 0、5、10、20、30、50、100。选择 0 表示只复习已有词。
- **翻面前显示假名提示：**默认开启。想练习认读汉字时可以关闭，翻面后仍会显示假名。
- **窗口保持置顶：**与顶部置顶按钮作用相同。
- **词库与顺序：**可多选 N5—N1；选择顺序学习、乱序或重新洗牌。
- **亮色／暗色、透明背景：**按桌面背景选择，透明度滑块调节背景浓度。
- **新卡出现时自动发音：**默认开启；取消勾选后仍可按 R 或点击「听发音」。
- **自然语音 · 离线／Windows 备用：**选择发音引擎。默认使用内置自然语音，不要求安装 Windows 日语语言包。
- **导出／导入进度：**用于备份与换电脑，见下一节。

## 升级、进度保存与搬家

从旧版升级时，先退出旧版并导出一份进度备份，再将新版完整解压到新文件夹，把旧程序旁的整个 `portable-data` 文件夹复制到新版程序旁。启动新版后会读取原有记录、收藏和设置；旧版单选等级会继续作为学习等级。不要用空的 `portable-data` 覆盖原有文件夹。也可在新版中导入之前导出的进度。


正常情况下，进度保存在程序旁的 `portable-data/progress.json`。每次评分、收藏或修改设置都会保存，写入采用先写临时文件再替换的方式；替换前的一份记录保留为 `progress.json.bak`。上一份备份会随下次保存更新，不能代替长期归档。

如果程序文件夹不可写，会改存到当前用户的 `%LOCALAPPDATA%\KotobaWindow` 文件夹，并显示提示。「设置 → 进度与备份」会列出实际保存路径。此时只复制程序文件夹不会带走学习进度，应使用导出功能。

换电脑的推荐方法：

1. 在原电脑的「设置」点击「导出进度」，保存 JSON 文件。
2. 在新电脑解压并打开程序。
3. 点击「导入进度」，选择刚导出的文件。

导入会替换当前的进度、收藏和设置，不会合并；先导出新电脑现有记录，可避免误覆盖。程序会校验导入文件，格式不正确时保留原进度。正常退出后整体复制程序文件夹及其 `portable-data`，也能搬走便携模式下的进度。

## 日语发音

默认使用随包内置的 **Supertonic 3 日语神经语音**，由 sherpa-onnx 在本机合成，无需联网、账号、API 密钥或 Windows 日语语言包。它是 AI 合成发音，不是真人录音。程序优先朗读词条的假名，帮助避免孤立汉字被读成其他读音；AI 发音仍可能存在读音或声调偏差。

新卡出现时默认自动朗读，手动按 R 或点击「听发音」可以重播。在「设置」取消「新卡出现时自动发音」即可关闭自动播放。切换卡片会停止旧词发音；隐藏窗口或离开背单词页面也不会继续排播。

每个未缓存的词第一次需要几秒生成音频，本次测试约 4 秒，实际时间随电脑性能变化。生成成功后保存在学习数据文件夹下的 `voice-cache`，再次播放会直接读取缓存。缓存最多约 128 MB，程序会自动清理较早的音频；清理缓存不影响学习进度，需要时会重新合成。

请保留完整的 `voice` 文件夹及其中的模型、运行库。如果设置中提示语音文件缺失，重新完整解压新版便携包。模型文件与语音许可随包保留，不要只复制主程序。

「设置 → 发音 → Windows 备用」可手动切换回本机 Windows 日语语音。这个备用选项需要已经安装、且能被应用语音接口识别的日语语音；仅添加日语键盘不等于安装语音组件。如果系统没有可用语音，可以切回「自然语音 · 离线」。
