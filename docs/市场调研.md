# 小词窗：市场调研与功能取舍

调研日期：2026-10-29。范围为 Anki、jpdb、Mochi 的官方产品和帮助资料。目标是为中文母语的日语学习者提供一个可在 Windows 工作间隙使用、便携且能离线复习的桌面卡片工具。

## 调研结果

| 参考工具 | 官方资料中可确认的做法 | 小词窗中的取舍 |
| --- | --- | --- |
| Anki | 先显示问题，再翻面；使用 Again／Hard／Good／Easy 评价回忆情况；区分新词与到期复习；空格和数字快捷键降低操作成本 | 采用先回忆、后看中文的卡片流程，四级评分和预览间隔，当前等级内到期优先 |
| jpdb | 日语词汇与汉字学习相结合；复习默认隐藏答案；空格显示答案，R 重播读音；对遗忘与困难作区分 | 使用 R 发音，遗忘词进入短期重学；以独立词条 ID 保存学习记录；本版不实现其汉字依赖和文本分析功能 |
| Mochi | 本地优先、离线学习，简洁卡片，模板化信息和搜索；反向卡分别管理学习进度 | 采用无需账户的本地保存、词库搜索和可切换假名提示；本版只实现日语→中文，暂不提供反向卡 |

这些产品展示了共同思路：主动回忆比一直显示答案更适合自测；按回忆情况安排复习比纯随机切词更实用；快捷键、低干扰布局和可靠的本地进度保存有助于持续使用。

## 本版实际实现

1. **Windows 浮窗。** 无边框原生卡片窗口，可拖动、调大小、置顶、切换紧凑尺寸，并可隐藏到托盘。Ctrl + Alt + J 全局显示／隐藏。浮窗是本项目针对桌面场景的设计，并非声称三个参考产品都有同样功能。
2. **N5—N1 中文词库。** 随包内置 10,641 词，假名与中文分字段呈现。默认正面显示假名，也可关闭提示；翻面显示释义和备注。
3. **简单间隔复习。** 每日默认 20 个新词，跨等级共用额度，当前等级到期词优先。支持忘记、困难、记得、轻松四级评分、下一次间隔预览和撤销最近评分。
4. **低成本操作。** Space 翻面、1—4 评分、R 朗读、F 收藏、Ctrl + Z 撤销；输入框编辑时不截获学习快捷键。
5. **检索与自由查看。** 按日语、假名、中文检索，配合等级和收藏筛选；最多显示前 200 条匹配。自由查看不影响复习进度。
6. **可携带进度。** 默认保存在程序旁的 portable-data；目录不可写时回退到当前用户的 LocalAppData。支持导出／导入、替换前备份和损坏文件恢复逻辑。
7. **可选系统朗读。** 调用兼容本应用的 Windows 日语语音，不捆绑录音；缺少语音时明确提示，不阻止背词。

## 为什么不照搬所有功能

本版的重点是稳定可用的免安装 Windows 工具，没有实现账号体系、云同步、媒体词汇提取、按已知词选择例句、真人音频库或多方向学习排程。这些功能需要更多数据、服务或独立的学习状态。

本版的复习算法是简单间隔规则，**不是 FSRS，也不是 jpdb 的专有模型**，不使用这些名称宣传算法效果。四级按钮模仿的是成熟产品的交互习惯：忘记代表回忆失败，困难代表想对但吃力。

若未来加入中文→日语反向卡，应遵循 Mochi 的做法，为不同方向分别保存历史和复习时间；不能把同一个排程直接当成两种能力均已掌握。

## 词库说明

各级规模为 N5 807、N4 757、N3 1,817、N2 3,215、N1 4,045，共 10,641 条。分级来自社区学习资料，并非 JLPT 官方完整考试词表。中文释义与文本词库使用 egg rolls 的「JLPT N1–N5 一万词 v3.5」，按 CC BY-NC 4.0 署名及非商业许可提供；详情见「词库来源与许可.md」或开发目录 docs/VOCAB_SOURCE.md。未打包上游音频。
